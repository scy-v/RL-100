# RL-100 训练命令

命令从仓库根目录执行，按离线训练、在线训练的顺序组织。任务为 `adroit_door_medium`；先准备 `RL-100/data/adroit_door_medium.zarr` 和 R3M 权重，安装见[安装命令](安装命令.md)。本次仅核对入口和参数，没有重新运行训练。

## 1. 激活环境

```bash
cd /home/suchenyu/RL-100
source rl100-setup/activate.sh
```

历史数据校验见[验证报告](reports/verification.json)。3D 单动作还有配置不同的两阶段多卡入口，此处沿用作者命令选择器的单卡入口；其他离线命令显式指定四卡。离线默认搜索前 4 组，`--max-combinations 0` 搜索全部候选；GPU 默认自动选择。当前命令参数与历史运行可能不同，不能覆盖历史实验条件。

完成 BC、critic/dynamics 和离线 RL；单步使用单卡，多步默认四卡。

单步：

```bash
bash scripts/Diffusion/Offline/3D/train_policy.sh --alg-name rl100 --task adroit_door_medium --tag 0112 --seed 100 --max-combinations 4
```

```bash
bash scripts/Diffusion/Offline/3D/train_policy_chunk_two_stage.sh --alg-name rl100 --task adroit_door_medium --tag 0112 --seed 100 --num-gpus 4 --max-combinations 4
```

## 5. 2D Flow 离线训练

完成 BC、critic/dynamics 和离线 RL；单步、多步命令均指定四卡。

单步：

```bash
bash scripts/Flow/Offline/2D/train_policy_image_unet_two_stage_flow.sh --alg-name rl100 --task adroit_door_medium --tag 0112 --seed 100 --num-gpus 4 --max-combinations 4
```

多步（action chunk）：

```bash
bash scripts/Flow/Offline/2D/train_policy_image_unet_flow_chunk_two_stage.sh --alg-name rl100 --task adroit_door_medium --tag 0112 --seed 100 --num-gpus 4 --max-combinations 4
```

单步、多步离线搜索均默认取前 **4 组**；`--max-combinations 0` 跑全部候选（多步原始网格为 54 组）。`--num-gpus` 为 GPU 数；所有命令支持命名参数、旧位置参数及 `--help`。

在线训练加载对应离线模型，单步使用单卡；多步先完成相同任务、tag、seed 的多步离线训练，再用四卡预蒸馏和单卡在线训练。已有蒸馏文件会跳过预蒸馏，旧学生重新蒸馏前先核对对应文件。
