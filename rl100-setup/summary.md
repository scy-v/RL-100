# 实验总结

## 1. 2D 与 3D 的速度差异

当前 Door 配置中，2D 比 3D 慢，主要因为其**输入数据量更大、编码器参数量更多、计算量更大**：2D 使用 ResNet18 对密集图像反复进行卷积，而 3D 使用较轻的点云编码器。3D 只有 512 个点，是因为作者先将深度图转为点云，再裁剪掉工作区域外的点，通过最远点采样选取 512 个代表点，以减少计算并保留主要几何结构。

| 指标 | 2D Diffusion | 3D Diffusion |
|---|---:|---:|
| 单帧编码器输入 | `224×224×3` | `512×3` |
| 观测编码器参数量 | 1,227 万 | 223 万 |
| BC 单步耗时 | 199.63 ms | 31.83 ms |
| 峰值分配显存 | 9,416 MiB | 2,097 MiB |

同卡同 batch 下，**2D 单步耗时为 3D 的 6.27 倍，97.7% 的额外耗时来自观测处理及编码的前向、反向，动作去噪网络耗时接近**。

测试条件：RTX 4090 D、FP32、batch 128、3 帧观测；仅测 BC 计算，不含数据加载、评估及存盘。[原始指标](reports/diffusion-speed.json)
